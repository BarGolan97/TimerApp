# ⏱️ TimerApp — Timers for Apple Vision Pro

**A visionOS app for creating and running timers in your space on Apple Vision Pro.**

---

## ✨ Features

- Create and run timers in a spatial window
- Audio alerts when a timer finishes

---

## 🛠️ Built With

- **Swift** · **SwiftUI** · **RealityKit** · **visionOS**
- Built with AI-assisted development (Claude Code)

---

## ▶️ Running the Project

1. Open `TimerApp.xcodeproj` in **Xcode** (with the visionOS SDK installed)
2. Select the **Apple Vision Pro** simulator
3. Press **Run** (⌘R)
